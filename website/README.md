# MrPing public website

A standalone, dependency-free public landing page for MrPing.

## Files

- `index.html` — page structure and Persian/English content
- `styles.css` — responsive dark theme and visual identity
- `script.js` — language switch and mobile navigation

## Local preview

Open `index.html` directly in a browser, or serve this folder with any static HTTP server.

## Before production

1. Set the public domain's document root to this directory.
2. Add the real customer-panel URL and Telegram bot URL after confirming their deployed addresses.
3. Replace the text-based wordmark with the final approved MrPing logo asset if desired.
4. Verify all claims and plan details against the live service before publishing.

The site does not connect to the Doctor DNS database or expose any API credentials. Customer and admin panels remain separate applications.
